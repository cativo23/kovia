1. **useApplicationDraft composable** — Create `frontend/app/composables/useApplicationDraft.ts`:
```typescript
export function useApplicationDraft(animalId: string, userId: string) {
  const key = `aplicacion_draft_${animalId}_${userId}`

  function saveDraft(currentStep: number, data: Record<string, any>) {
    const existing = loadDraft() || { steps: {} }
    existing.steps[`step${currentStep}`] = data
    existing.currentStep = currentStep
    existing.savedAt = Date.now()
    localStorage.setItem(key, JSON.stringify(existing))
  }

  function loadDraft(): { steps: Record<string, any>; currentStep: number; savedAt: number } | null {
    if (import.meta.server) return null
    const raw = localStorage.getItem(key)
    return raw ? JSON.parse(raw) : null
  }

  function clearDraft() {
    if (import.meta.server) return
    localStorage.removeItem(key)
  }

  return { saveDraft, loadDraft, clearDraft }
}
```

| Boundary | Description |
|----------|-------------|
| localStorage -> API | Draft data from localStorage re-submitted to server — must be re-validated server-side |
| Unauthenticated user -> wizard | Auth middleware prevents unauthenticated access |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08 | Tampering | localStorage draft | mitigate | Draft data is re-validated via Zod on each step before sending to server; server-side class-validator DTOs are authoritative |
| T-03-09 | Spoofing | aplicar.vue | mitigate | definePageMeta({ middleware: 'auth' }) enforces authentication before wizard renders |
| T-03-10 | Information Disclosure | /perfil/aplicaciones/[id] | mitigate | Backend ownership check (app.userId === req.user.sub) prevents viewing others' applications |
| T-03-11 | Elevation of Privilege | Withdraw action | mitigate | Backend validates ownership + status !== ADOPTADA before allowing withdrawal |
</threat_model>
