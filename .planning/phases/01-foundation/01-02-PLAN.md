    1. Create Passport strategies:
       - `LocalStrategy`: validates email + password via bcrypt compare, checks emailVerified and isActive
       - `JwtStrategy`: extracts access token from Authorization Bearer header, validates and returns user payload
       - `JwtRefreshStrategy`: extracts refresh token from httpOnly cookie, validates against hashed token in DB
       - `GoogleStrategy` (passport-google-oauth20):
         - Client ID and secret from env vars (GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET)
         - Callback URL: `http://localhost:3000/auth/google/callback` (per Pitfall 5 in research)
         - Scope: ['email', 'profile']
         - `validate(accessToken, refreshToken, profile)`: upsert user by googleId or email. Set emailVerified=true. No password needed. Return user.

    2. Create guards:
       - `JwtAuthGuard` (global default with @Public() bypass via Reflector)
       - `LocalAuthGuard`
       - `GoogleAuthGuard`
       - `RolesGuard` checking user role against @Roles decorator

    3. Create `AuthController` endpoints:
       - `POST /auth/register` (public) -> register
       - `POST /auth/login` (LocalAuthGuard) -> login, sets refresh cookie
       - `POST /auth/verify-email` (public) -> verifyEmail, body: { token }
       - `POST /auth/forgot-password` (public) -> requestPasswordReset
       - `POST /auth/reset-password` (public) -> resetPassword
       - `POST /auth/refresh` (JwtRefreshStrategy) -> refreshTokens
       - `POST /auth/resend-verification` (public) -> resendVerification
       - `POST /auth/logout` (JwtAuthGuard) -> clear refresh cookie + delete token from DB
       - `GET /auth/me` (JwtAuthGuard) -> return current user profile
       - `GET /auth/google` (GoogleAuthGuard) -> initiates OAuth redirect
       - `GET /auth/google/callback` (GoogleAuthGuard) -> handles callback, generates tokens, redirects to frontend with access token as query param
