<action>
Create useNotifications composable that provides:

1. `notifications` — ref<Notification[]> (recent notifications, fetched on demand)
2. `unreadCount` — ref<number> (count of unread notifications)
3. `loading` — ref<boolean> (loading state)
4. `error` — ref<string | null> (error state)

Methods:
1. `fetchNotifications(limit?: number)` — GET /notifications, updates notifications ref
2. `fetchUnreadCount()` — GET /notifications (uses unreadCount from response), updates unreadCount ref
3. `markAsRead(notificationId: string)` — POST /notifications/:id/read, updates local state
4. `markAllAsRead()` — POST /notifications/read-all, clears unreadCount

Polling behavior (per D-02): No continuous polling. Fetch on:
- Page load (component mount)
- When bell icon is clicked/opened
- After marking a notification as read

The composable should use the existing API client (with JWT auth headers) for all requests.
</action>

- markAsRead() calls POST /notifications/:id/read
- markAllAsRead() calls POST /notifications/read-all
- No setInterval or polling loop (fetch-on-demand only)
- Composable is TypeScript-typed with Notification interface
