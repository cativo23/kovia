# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-04-21
**Phases:** 1–5
**Total Plans:** 19

## Overview

Kovia v1.0 delivers a fully operational multi-tenant pet adoption platform. Starting from a blank repo, it ships: a Docker-based full stack (NestJS 11, Nuxt 4, PostgreSQL 16 + RLS, Redis, MinIO, n8n), complete auth with org onboarding, animal management with photo uploads and SSR public listings, a structured multi-step adoption application with state machine, a rule-based scoring engine with 50+ TDD tests, staff tools including internal notes and applicant history, and in-app notifications with a webhook outbox for n8n automation.

- [x] 01-03-PLAN.md — Auth frontend: pages, Pinia store, API client, layouts, i18n, frontend unit tests

## Milestone Summary

**Key Decisions:**
- Nuxt 4 over Nuxt 3 — Nuxt 3 EOL July 2026; greenfield on Nuxt 4 avoids immediate migration
- RLS in Phase 1 first migration — retrofitting requires full audit; done right from the start
- Spanish-first (es-SV) — pilot org (DameTuPataSV, El Salvador) requires it
- Prisma 7 + driver adapter + SWC builder — specific compatibility constraints documented
- Docker-only development — host has zero dependencies; all tooling via docker run/compose
- Global n8n automation — simpler architecture; per-org config deferred to v2
- Rule-based scoring — simpler to build, validate, and debug than AI-based for v1
- AUTH-05 (Google OAuth) — deferred to v2; route partially wired but not implemented

**Issues Resolved:**
- Prisma 7 ESM/CJS compatibility with SWC builder (typeCheck disabled)
- Prisma client destruction across bind mount (anonymous volume solution)
- RLS compatibility with Prisma driver adapter (disabled on platform-level tables)
- HandlebarsAdapter ESM import path for NestJS mailer
- Nitro proxy for same-origin cookies in Docker
- Photo reorder persistence (optimistic update + rollback pattern)
- BullMQ notifications RLS incompatibility (batch transactions with admin bypass)

**Technical Debt:**
- AUTH-05 (Google OAuth) route wired but callback not fully implemented — v2 item
- Phase 01/02/04 verification artifacts have `human_needed` / `gaps_found` statuses — deferred at close
- Phase 02 UAT has 2 pending human scenarios — deferred at close
