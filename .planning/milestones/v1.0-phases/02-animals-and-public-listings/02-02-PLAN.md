API Endpoints (from Plan 01):
```
# Org-scoped (require auth + ORG_ADMIN):
POST   /animals                    — create animal (body: CreateAnimalDto)
PATCH  /animals/:id                — update animal (body: UpdateAnimalDto)
PATCH  /animals/:id/status         — change status (body: { status })
PATCH  /animals/:id/archive        — archive animal
PATCH  /animals/:id/restore        — restore from archive
DELETE /animals/:id                — hard delete
POST   /animals/:id/photos         — add photos (body: [{ url, key, caption? }])
DELETE /animals/:id/photos/:photoId — remove photo
PATCH  /animals/:id/photos/cover   — set cover (body: { photoId })
PATCH  /animals/:id/photos/reorder — reorder (body: { photoIds: string[] })
GET    /animals/org                — list org animals (?page, ?limit, ?status, ?search)
GET    /animals/org/stats          — { total, available, inProcess, adopted, archived }
GET    /animals/org/:id            — single animal for editing

# Upload:
POST   /upload/presigned-url       — { filename, contentType } -> { url, key }

# Species (public):
GET    /species                    — list all species [{ id, name, slug }]
```
