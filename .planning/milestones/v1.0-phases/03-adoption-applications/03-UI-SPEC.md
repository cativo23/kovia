## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, step connector height |
| sm | 8px | Compact element spacing, input inner padding |
| md | 16px | Default element spacing, form field gaps (`space-y-4`) |
| lg | 24px | Section padding, card padding, page header margin-bottom |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Major section breaks, wizard top margin |
| 3xl | 64px | Page-level spacing (empty state vertical padding) |

Exceptions:
- Step indicator circles: 32px (8 Tailwind units, `w-8 h-8`) — matches existing wizard pattern
- Touch targets for mobile (buttons, nav links): minimum 44px height
- Sidebar width: 256px (`w-64`) — matches existing org layout

Source: Observed from `nuevo.vue`, `org.vue`, `index.vue` (dashboard) existing patterns.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (`text-base`) | 400 (regular) | 1.5 |
| Label | 14px (`text-sm`) | 400 (regular) | 1.4 |
| Heading | 24px (`text-2xl`) | 700 (bold) | 1.2 |
| Display | 30px (`text-3xl`) | 700 (bold) | 1.2 |

Notes:
- Step labels in wizard: 14px (`text-sm`) weight 400 — matches existing wizard pattern
- Section headers within form steps: 16px (`text-base`) weight 700 — use `font-bold` class
- Badge labels: 14px (`text-sm`) — rendered by `UBadge` component
- Table cell primary text: 16px (`text-base`) weight 400 for names/titles
- Error messages below inputs: 14px (`text-sm`) weight 400, color `text-red-500`
- Primary CTAs ("Enviar solicitud", "Siguiente"): 16px weight 700

Declared sizes: 14px, 16px, 24px, 30px (4 total — maximum).
Declared weights: 400, 700 (2 total — maximum).

Source: Observed from `nuevo.vue`, `AnimalForm.vue`, `org.vue`, `index.vue` (listings page).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-white` / `dark:bg-gray-900` | Page surfaces, sidebar, header, card backgrounds |
| Secondary (30%) | `bg-gray-50` / `dark:bg-gray-950` | Main content area background (`<main>` in org layout), form step backgrounds |
| Accent (10%) | Nuxt UI `primary` (runtime token) | See reserved list below |
| Destructive | Nuxt UI `error` / `text-red-500` | Withdraw application confirmation, required field asterisks, input validation errors |

Accent (`primary`) reserved for:
1. Active step indicator circle fill (`bg-primary text-white`)
2. Completed step indicator circle fill (`bg-primary text-white`)
3. Step connector line fill when step is complete (`bg-primary`)
4. Active nav link background tint (`bg-primary/10`) and text (`text-primary`)
5. Primary CTA buttons ("Enviar solicitud", "Siguiente")
6. Upload drop zone border on drag-active state (`border-primary bg-primary/5`)
7. Photo count / progress indicator
8. Brand header logo and title (`text-primary`)
9. "Ver solicitud" link-style button on animal detail (existing application state)
10. Pagination active page

Secondary semantic colors (Nuxt UI semantic system):
- `success`: Application status `aprobada`, `adoptada`
- `warning`: Application status `seguimiento`, `revisando`
- `error` / `destructive`: Application status `rechazada`, validation errors, withdraw action
- `info`: Application status `enviada`
- `neutral`: Inactive step indicators, placeholder text, secondary labels

Source: Observed from `StatusBadge.vue`, `nuevo.vue`, `org.vue`, `PhotoUploader.vue` color patterns.

## Page-Level Layout Contracts

### `/animales/[id]/aplicar` — Application Wizard (adopter)

- Layout: `default` (public layout, requires auth middleware)
- Container: `max-w-3xl mx-auto` — matches existing wizard container
- Back link: `text-sm text-gray-500 hover:text-primary` with `i-lucide-arrow-left` icon — links to `/animales/[id]`
- Page heading: `text-2xl font-bold` + animal name as subtitle `text-base text-gray-500`
- Step indicator: 5 circles + 4 connectors — same pattern as `nuevo.vue`
- Step labels (visible on sm+ screens): "Info personal", "Vivienda", "Experiencia", "Fotos del hogar", "Revisión y envío"
- Card: single `UCard` housing current step content

## Interaction Contracts

### Auth Gate Modal (animal detail page)

- Trigger: unauthenticated user clicks "Aplicar para adoptar" button on `/animales/[id]`
- Component: `UModal` — does NOT navigate away, preserves animal detail context
- Modal title: "Necesitás una cuenta para aplicar"
- Two equal-width buttons stacked vertically on mobile, side by side on sm+:
  - Primary: "Crear cuenta" → opens inline auth form or redirects `/auth/register?redirect=/animales/[id]/aplicar`
  - Secondary: "Iniciar sesión" → opens inline auth form or redirects `/auth/login?redirect=/animales/[id]/aplicar`
- On successful auth: redirect to `/animales/[id]/aplicar` automatically

### "Aplicar para adoptar" Button States (animal detail)

- Unauthenticated: `UButton` with label "Aplicar para adoptar" → opens auth modal
- Authenticated, no application: `UButton` with label "Aplicar para adoptar" → navigates to `/animales/[id]/aplicar`
- Authenticated, application exists: `UButton variant="outline"` with label "Ver solicitud" → navigates to `/perfil/aplicaciones/[id]`
- Animal not in `AVAILABLE` status: button disabled with `disabled` prop + tooltip "Este animal ya no está disponible"

### Draft Persistence UX

- Auto-save trigger: on each completed step advance (not on every keystroke)
- localStorage key: `aplicacion_draft_{animalId}_{userId}`
- On page load with existing draft: show `UAlert variant="soft" color="info"` at top of wizard
  - Copy: "Tenés un borrador guardado de esta solicitud. ¿Querés continuar desde donde lo dejaste?"
  - Actions: "Continuar borrador" (primary) + "Empezar de nuevo" (neutral/ghost)
- On successful submission: clear draft from localStorage automatically
- Auto-save indicator: `text-xs text-gray-400` — "Guardado" with timestamp, updated after each save

### Step Validation (form steps 1–3)

- Zod schema per step — validated on "Siguiente" click before advancing
- On validation failure: error messages appear below each invalid field (`text-sm text-red-500 mt-1`) — same pattern as `AnimalForm.vue`
- Fields scroll into view on first error (browser native scroll behavior)
- Cannot advance to next step with invalid data

### Photo Upload Step (Step 4)

- Reuses `AnimalsPhotoUploader` adapted with: min=2, max=8, label "Fotos de tu hogar"
- Minimum indicator: inline text below uploader — "Se requieren mínimo 2 fotos" (`text-sm text-gray-500`)
- If < 2 photos, "Siguiente" button is disabled with tooltip "Agregá al menos 2 fotos para continuar"
- Drop zone: same drag-and-drop UX as `PhotoUploader.vue` (dashed border, drag-active state with `border-primary bg-primary/5`)

### Staff Status Transitions

- Inline in application detail page (right sidebar panel) — no inline-table dropdown
- Each allowed transition rendered as a `UButton` with semantic color:
  - `enviada → revisando`: `UButton color="info"` — "Marcar en revisión"
  - `revisando → aprobada`: `UButton color="success"` — "Aprobar"
  - `revisando → rechazada`: `UButton color="error"` — "Rechazar"
  - `revisando → seguimiento`: `UButton color="warning"` — "Solicitar seguimiento"
  - `seguimiento → aprobada`: `UButton color="success"` — "Aprobar"
  - `seguimiento → rechazada`: `UButton color="error"` — "Rechazar"
  - `aprobada → adoptada`: `UButton color="success"` — "Confirmar adopción"
- All transitions open `UModal` confirmation before calling the API
- Buttons are full-width (`block`) in the right-column sidebar panel

### Adopter Withdraw

- Trigger: "Retirar solicitud" button on `/perfil/aplicaciones/[id]`
- `UModal` confirmation required before API call
- Only available when application status is not `adoptada`
